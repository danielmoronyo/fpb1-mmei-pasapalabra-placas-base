PASAPALABRA TECH TRILINGÜE (Versión Web Estática)
===================================================

Estructura del proyecto:
- index.html        -> Estructura principal de la aplicación (Menú, Rosco de Juego y Resultados).
- css/styles.css    -> Estilos visuales responsive, animaciones del rosco y tema oscuro tecnológico.
- js/questions.js   -> Banco completo de preguntas en 3 idiomas (Castellano con Ñ [27], Valencià [26], English [26]) y 3 roscos por idioma (9 roscos en total).
- js/app.js         -> Lógica del juego, temporizador, validación tolerante a tildes/mayúsculas, vueltas de Pasapalabra y pantalla de revisión.
- img/favicon.svg   -> Icono vectorial del rosco.
- img/logo-rosco.svg-> Logotipo vectorial para la pantalla de resultados.

Cómo ejecutarlo:
Simplemente haz doble clic sobre `index.html` para abrirlo en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari) sin necesidad de servidor ni dependencias externas.
